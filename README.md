# STARFALLGODOT — Phase 03 Prototype

Godot 4 prototype project. See:
- [Prototype scope](docs/phase-03/prototype-scope.md)
- [Run and test](docs/phase-03/run-and-test.md)
- [Phase 03 status](docs/phase-03/phase-03-status.md)
- [Phase 03 handoff](docs/phase-03/phase-03-handoff.md)

This is a prototype, not a production-ready game. Combat values and turn order are temporary test parameters. The solo encounter is offline; online group play is not implemented.

Godot 4.7.2 stable is the prototype baseline only. The final production engine version and renderer remain open decisions.
