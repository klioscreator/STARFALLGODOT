# STARFALLGODOT

STARFALLGODOT is a game project developed in 7 sequential phases (design, architecture, prototype, combat, creatures, world base, integration). The Project Owner directs the work, and AI assistants carry out individual phases under an AI Coordinator.

The repository currently contains project-management documentation only.
